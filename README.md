# Платформа онайн-курсов
Платформа-агрегатор образовательных программ по различным ИТ-направлениям. Функционал системы включает возможность разработки и размещения учебных материалов, их прохождения, контроля прогресса обучения, администрирования контента и приёма оплаты за образовательные услуги.
# Задача
Разработать прототип современной online-школы с логичной структурой и понятными правилами взаимодействия всех участников. Проект призван продемонстрировать навыки аналитической работы: сбор требований, их документирование и построение наглядных связей между элементами системы.
# Участники
Студент — осваивает курсы, решает практические задачи, наблюдает за своим продвижением и получает сертификаты.
Автор — формирует курс, загружает обучающие материалы, ведёт группы учащихся и следит за их успеваемостью.
# Ключевые заинтересованные стороны
заказчик со стороны бизнеса, маркетологи, разработчики.
